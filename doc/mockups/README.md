# Mockups

## android_app_mockup.html

Interactive browser mockup of the FluidLevelMonitor Android app.

Open in any modern browser. Includes four interactive screens:
- **Dashboard** — live tank level, alert banner, quick pump control
- **Pump Control** — mode selector (Off / Auto / On), threshold sliders, safety info
- **Sensor Status** — connectivity health, sensor readings, filter pipeline visualization
- **Settings** — device address, alert thresholds, tank config, SudarshanChakra integration

The mockup is pixel-accurate to the planned Compose UI and can be used
for stakeholder reviews before Android development begins.

**SudarshanChakra (SC) app:** treat this mockup as a **design reference** for future SC Android water/motor screens (dashboard, pump, sensor, settings), not a shipped SC binary.
